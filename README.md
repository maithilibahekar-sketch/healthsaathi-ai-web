# HealthSaathi AI - Rural Healthcare Platform
A web application to provide AI-based healthcare assistance for rural areas.

## Features
- AI Symptom Checker (English, Hindi, Marathi)
- Find Nearby Hospitals (Gondia District)
- Health Records Management
- Vaccination Reminder
- Emergency SOS

## Tech Stack
- React + TypeScript + Vite
- Tailwind CSS
- Supabase
